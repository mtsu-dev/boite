# ADEMark's tests on Boite, Linux, 2026-11-14

ADEMark v1 (published 2026-11-12) times 15 agentic development environments
on a Mac mini M4 against Claude Code alone in a terminal, with Claude Opus 5.5
at high effort. Boite is not in it. `bench/ademark/` plays its twelve ranked
tests on Linux, on Boite and on Claude Code alone, so the two can be compared
on one machine.

## Method and its limits

- Boite is the compiled core (`bun run build:core:linux`) and the production
  UI (`bun run build:ui`) in headless Chrome. **The Tauri shell is not
  measured**: its start, its memory and its webview differ from Chrome's.
- The Bare CLI is Claude Code 2.1.325 in a pseudo-terminal with no terminal
  application: its echo is the moment Claude Code writes the character back,
  and no terminal's memory or CPU is counted. ADEMark ran 2.1.303 in Ghostty.
- Times are read in the page (`requestAnimationFrame`, `MutationObserver`),
  not from a screen recording: they leave out the compositor and the display.
- Memory is PSS of the core, the browser and their children. CPU comes from
  `/proc`.
- Track A answers every model request from ADEMark's replay server, so it
  spends no token. Track B is live: `hi` three times and one read-only prompt,
  each on a new thread in a fresh copy of ADEMark's arena, counted until 30 s
  after the last request.
- This machine (16 threads, 31 GB) ran other agents during every run: its
  load average stayed between 15 and 55. Times moved by a factor of two from
  one run to the next with no code change, so **a time here is an order of
  magnitude, not a result**; byte and token counts did not move.
- BoiteOS adds a managed instructions file and a session hook to every Claude
  request here, on Boite and on the Bare CLI alike, so token counts are not
  the published ones: the Bare CLI's `hi` costs 20,044 tokens here and 38,226
  in the published run.
- C1, the orchestrated build, was not run: it is not one of the twelve ranked
  tests, one run costs two to three million tokens, and its hidden tests are
  not in the public harness.

## Where Boite would stand

ADEMark publishes no overall winner. Its results grid has a default order,
"like a medal table": tests led, then places in the top third behind the
leader, then in the middle third, with equal tallies sharing a position and
no position for an app measured in fewer than 9 of the 12 tests. It calls
that order a help for scanning, not a score. `bench/ademark/rank.ts` applies
the same rules to the `After` numbers beside the published ones. **This is
not an ADEMark result**: Boite was not run by ADEMark, on its machine or with
its method. The token tests are placed twice: by their count, and by their
ratio to the Bare CLI measured beside them (`--bare`), here and in the

## Where the memory is

`A5` and `A7` count headless Chrome, which is not the application: the Tauri
shell's webview replaces it. Per process, PSS, same day:

| | Core | Headless Chrome | Claude Code agents |
| --- | ---: | ---: | ---: |
| At rest, 5 threads | 84 MB | 377 MB, 157 of it the GPU process | none alive |
| 5 agents working, 60 s in | 115 MB | 369 MB | 5 of 137 to 141 MB |

The core holds 37 MB of its own and 47 MB of its executable's pages at rest.
An agent is Claude Code's own process, the one the Bare CLI runs.

## The session title

Claude Code names every new session with one request on the session's own
model. A new thread of Boite sent four requests for its first prompt: the
agent's, the core's own title request on Haiku, and Claude Code's naming of
each of those two sessions, the agent's on Opus. Nothing in Boite reads those
names. The driver now passes the thread's title as the session's (`title` of
the Agent SDK), and a fixed one for its one-shot title and side-question
queries, so Claude Code sends neither.

| `hi` on a new thread, live | Requests | Tokens, three runs | Side calls |
| --- | ---: | --- | ---: |
| Before | 6 | 27,261, 27,559, 27,466 | about 10,000 |
| After | 3 | 22,540, 22,877, 22,553 | about 5,300 |
| Bare CLI | 1 | 20,044, 20,060, 20,032 | 0 |

The three requests left are the agent's and the core's two title requests
(the first prompt, then the first answer). The read-only prompt went from six
requests and 64,476 tokens to four and 60,513.

## What was tried and not kept

- Starting the core's title request three seconds after Enter, so that it
  does not start a second Claude Code beside the agent's first request: five
  alternated runs gave 388, 249, 566, 397 and 466 ms without it and 266, 234,
  396, 445 and 741 ms with it. No difference this machine can show.
- `disableAllHooks` on the title query: the managed hook still ran.
- Finding the tool line a turn's change count joins once a turn instead of
  once a row: 32 searches instead of 120 over the heavy-thread walk, and the
  click's long task at a median 148 ms before and 147 ms after over ten
  alternated opens.

## What is left

- A11: the click that opens the thread runs one task of 94 to 290 ms, median
  148 ms, and mounts 1,366 nodes. About half of it is style and layout, the
  rest Svelte effects. The cause is not found.
- A6: 0.87 % of a core over 60 s in a second measurement, 0.18 % of it the
  core. The page ran no animation, changed no node and its main thread took
  90 ms; the rest is headless Chrome's compositor drawing 60 frames a second
  on a page that does not change, which the shell's webview may not do.
- The first request carries eleven tool definitions, 23.8 KB of the 47.6 KB
  it sends. `ListAgents` (1.2 KB) and `ReportFindings` (2.3 KB) are Claude
  Code's own and no thread of Boite uses them.

## Commands

```sh
git clone https://github.com/zqkra/ademark <dir>   # at 31e2814: the arena and the replay server
bun run build:core:linux && bun run build:ui
export ADEMARK_DIR=<dir> BOITE_E2E_BROWSER=<chrome or chrome-headless-shell>
bun bench/ademark/run.ts --ade boite --out <out>       # Track A, no token spent
bun bench/ademark/run.ts --ade bare-cli --out <out>
bun bench/ademark/tokens.ts --ade boite --out <out>    # Track B, live: spends tokens
bun bench/ademark/tokens.ts --ade bare-cli --out <out>
bun bench/ademark/rank.ts --published <ademark results.json> --bare <bare out>/tokens.json <out>/results.json <out>/tokens.json
```
